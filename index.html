5. E‑Therapy Waveform Protocol

마스터 파형 / 모드 Reference 펼치기
업로드된 E‑Theraphy WaveForm 마스터 기준: Relax Mode = 60 Hz sine waveform(마스터 메모: 이완/부드러운 파장/언와인딩), EMS = Pulse waveform(마스터 메모: 통증관리 전용), Galvanic 1–9는 장비 용도별 모드로 구성. 아래 표현은 고주파(RF) 치료로 해석하지 않습니다.
마스터 메모: Galvanic 1·2 = 도자용, 3·4·5 및 8·9 = 대경TENS, 8·9 = EV Therapy. 이 중복 표기는 원본 마스터 내용을 그대로 보존한 것입니다.
